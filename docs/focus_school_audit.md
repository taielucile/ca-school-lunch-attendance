## Why this matters

A blanket 180-day multiplier is a useful full-year benchmark for the district comparison, but it should not be silently treated as a verified school-specific calendar for every charter.

The more important unresolved issue remains student exposure: even if a school offered exactly 180 instructional days, a student entering in March did not have 180 expected attendance days at that school.

## Special case: Rio Valley Charter

Rio Valley's public description identifies it as a personalized homeschool/independent-study charter. That is potentially substantively different from a conventional campus-based TK/K meal-access setting. The school should remain in the reproducible data universe, but the memo should flag it before deciding whether it belongs in the main meal take-up analytic sample.
