# Lodi Unified: kindergarten meals and estimated attendance (2025–26)

A reproducible, school-level **descriptive comparison** across 31 Lodi Unified schools for the Feed California Kinders research team. Meal numerators are kindergarten-labeled breakfast and lunch **counts** from district records. Denominators are **modeled kindergarten attended student-days** from CDE enrollment and jointly reported TK/K absences. These are *not observed K attendance days*, student counts, or validated meal participation rates.

## Rerun

From this study folder (or from another directory by using the full script path):

```sh
Rscript code/reproduce_lodi_2025_26.R
Rscript code/test_lodi_reproduction.R
```

The script reads files in `inputs/` and overwrites derived outputs in `outputs/`. No third-party R package is needed on the normal snapshot route. To use an original local copy of `Lodi Data_copy.xlsx` instead, run `Rscript code/reproduce_lodi_2025_26.R --meal-xlsx='/path/to/Lodi Data_copy.xlsx'`. That option requires R `readxl`, and **has not been tested in this environment**.

The school-level figure in the report uses the same checked school ratios. A PNG is generated by the R script. The committed SVG is a static presentation copy based on the same output table; it is not a separate analysis. To regenerate the static SVG and Word draft, run `python code/make_compact_svg.py` and `python code/build_district_report.py`. The first uses Python's standard library; the Word draft also needs `matplotlib` and `python-docx`. The `.docx` review copy is distributed separately from the repository's Markdown report.

## Calculation

For school \(i\):

```text
Modeled K ADA_i = K Census_i − (combined TK/K absences_i / 180)
                            × (K Census_i / (TK Census_i + K Census_i))
Modeled K days_i = modeled K ADA_i × 180
Breakfast ratio_i = 100 × K breakfast meals_i / modeled K days_i
Lunch ratio_i     = 100 × K lunch meals_i / modeled K days_i
```

The district-level ratios use **the sum of school meals divided by the sum of modeled attendance days**. Census Day kindergarten enrollment is an input, not the denominator. The model allocates absent days in proportion to Census enrollment and assumes 180 days. These assumptions have not been validated against district school-by-grade attendance.
